# 足球联赛概率计算器

**在线使用：<https://22able22.github.io/soccer-probability/>**

一个纯静态网页工具，用蒙特卡洛模拟计算足球联赛的**夺冠、升级、附加赛、保级**概率。
打开即用，无需安装、无需注册、不上传任何数据。

内置 **英超 · 西甲 · 意甲 · 德甲 · 法甲 · 中超 · 中甲** 七个联赛。

---

## 怎么用

打开上面的链接，然后：

1. **选择联赛** —— 默认留空，选一个才会开始
2. **（可选）选择轮次** —— 可以回到赛季中任意一轮，看当时的形势
3. **（可选）调整模拟次数** —— 默认 5 万次，追求小概率精度可调到 50 万次
4. **点击「开始计算」**

结果包含三部分：

- **当前积分榜** —— 截至所选轮次的真实排名
- **概率预测** —— 每队的期望积分、期望名次，以及落入各名次区间的概率
- **名次分布** —— 每队最终排在第 1～8 名的概率矩阵

### 附加功能

| 功能 | 说明 |
|---|---|
| **what-if** | 点「+ what-if」，指定某场未赛比赛的结果（比如"梅州 1-0 胜南通"），看概率怎么变 |
| **轮次回溯** | 「截至轮次」选第 20 轮，就是"如果站在第 20 轮当时的预测" |
| **主题切换** | 右上角按钮，依次是 自动 → 夜间 → 日间，选择会记住 |
| **数据源** | 「内置快照」离线可用；「获取最新数据」会去拉取 CI 刷新的最新赛果 |

> 「获取最新数据」优先用 jsDelivr / GitHub raw 上的仓库快照。数据由 GitHub Actions 每天刷新 3 次。
> 需要"分钟级实时"时，可在本地运行 `node bin/serve.js` 并在页面设置 `window.SOCCER_PROXY` 直连源站。

## 算的是什么

### 攻防强度

对每支球队，用已赛比赛估计进攻与防守强度，并做**收缩**处理，避免开局样本太少而失真：

```
att_i = 场均进球 / 联赛场均         （收缩到 1.0）
def_i = 场均失球 / 联赛场均

w = 已赛 / (已赛 + 6)               // 只踢了 2 场就大幅拉回平均，踢满 20 场基本用原始值
att_final = w × att + (1 − w) × 1.0
```

### 单场进球期望

```
λ_主 = 联赛场均 × 主场系数 × att_主 × def_客
λ_客 = 联赛场均 ÷ 主场系数 × att_客 × def_主
```

主场系数由数据估计（`sqrt(主场总进球 / 客场总进球)`，钳制在 1.00～1.60）。

### 采样与排名

主客队进球独立服从泊松分布。每次模拟重跑一遍剩余赛程，然后按联赛规则排名：

```
积分 → 净胜球 → 进球数 → 胜场 →（可选）相互战绩
```

跑 N 次之后，`P(名次 ∈ 区间) = 命中次数 / N`，就是页面上的百分比。

### 名次区间可配置

不同联赛的"升级/降级"含义不同，工具按联赛自动套用：

- **中甲** —— 冠军 / 升级（2 席）/ 降级
- **中超** —— 冠军 / 亚冠区 / 降级
- **英超** —— 冠军 / 欧冠区 / 欧联区 / 降级
- **西甲、意甲** —— 冠军 / 欧冠区 / 欧联·欧协 / 降级
- **德甲、法甲** —— 冠军 / 欧冠区 / 欧联区 / 降级 / 降级附加赛

顶级联赛不会出现"升级"这种无意义的列。

## 数据从哪来

解析懂球帝的联赛数据页（赛程页 + 积分榜页）。

积分榜页很关键：中甲 2026 赛季有 4 支球队被扣分（宁波 −3、梅州 −9、苏州 −3、亚泰 −4），
赛程页完全看不出来。工具用「按赛果算出的积分 − 官方积分」反推扣分值，确保积分榜与官方逐队吻合。

GitHub Actions 每天自动重新抓取 3 次并提交，页面上的「获取最新数据」读的就是这些快照。

## 已知限制

1. **不建模伤病、轮换、一周双赛** —— 模型只看进球率，不看赛程密度
2. **不看赛季中转会与换帅** —— 除非该队之后踢了足够多比赛
3. **升级附加赛按 50/50 处理** —— 只算"进入附加赛区"的概率，不模拟附加赛本身
4. **同分规则依赖联赛配置** —— 默认 积分 → 净胜球 → 进球数 → 胜场，需要时可改用相互战绩
5. **精度** —— 5 万次模拟时标准误约 ±0.22 个百分点；想看 0.1% 量级建议 50 万次以上
6. **数据源单一** —— 只解析懂球帝
