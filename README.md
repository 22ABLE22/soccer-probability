# 足球计算器

**在线使用：<https://22able22.github.io/soccer-probability/>**

纯前端网页工具，用蒙特卡洛模拟计算足球联赛的**夺冠、升级、附加赛、保级**概率。
打开即用，无需安装、无需注册、不上传任何数据。

内置 **英超 · 西甲 · 意甲 · 德甲 · 法甲 · 中超 · 中甲**，也支持你自己的联赛（校级联赛、业余联赛都行）。

---

## 怎么用

打开上面的链接，然后：

1. **选择联赛** —— 默认留空，选一个就会自动载入数据
2. **（可选）选择截至轮次** —— 回到赛季中任意一轮，看当时的形势
3. **（可选）调整模拟次数** —— 默认 5 万次；想看 0.1% 量级的小概率可调到 50 万次
4. **点击「开始计算」**

结果分三块：

- **当前积分榜** —— 截至所选轮次的真实排名
- **概率预测** —— 每队的期望积分、期望名次，以及落入各名次区间的概率
- **名次分布** —— 每队最终排在第 1～8 名的概率矩阵

### 其他功能

| 功能 | 说明 |
|---|---|
| **what-if** | 点「+ what-if」，指定某场未赛比赛的结果（比如"梅州 1-0 胜南通"），看概率怎么变 |
| **轮次回溯** | 「截至轮次」选第 20 轮，就是"如果站在第 20 轮当时的预测" |
| **主题** | 右上角按钮，依次是 自动（跟随系统）→ 夜间 → 日间，选择会记住；也可用 `?theme=dark` 直接指定 |
| **获取数据** | 「内置快照」离线可用；「获取数据」拉取每日刷新的最新赛果 |

## 想加自己的联赛？

完全可以。校级联赛（各学院组队）、院系杯、业余联赛都能算。

**做法：往 `data/` 目录放一个 JSON 文件**，提交后自动重新构建，页面上就会多出一个联赛。

文件名随意（推荐 `联赛名-赛季.json`），格式如下：

```json
{
  "id": "college-cup",
  "name": "学院杯",
  "season": "2026",
  "teams": [
    { "id": "cs", "name": "计算机学院" },
    { "id": "ee", "name": "电子学院" },
    { "id": "me", "name": "机械学院" },
    { "id": "fl", "name": "外语学院" }
  ],
  "matches": [
    { "id": "m1", "round": 1, "home": "cs", "away": "ee", "homeGoals": 3, "awayGoals": 1 },
    { "id": "m2", "round": 1, "home": "me", "away": "fl", "homeGoals": 2, "awayGoals": 2 },
    { "id": "m3", "round": 2, "home": "ee", "away": "me" }
  ],
  "points": { "win": 3, "draw": 1, "loss": 0 },
  "tiebreak": ["points", "gd", "gf", "wins"],
  "slots": [
    { "from": 1, "to": 1, "type": "title",      "label": "冠军" },
    { "from": 2, "to": 2, "type": "runnerup",   "label": "亚军" },
    { "from": 3, "to": 4, "type": "relegation", "label": "降级" }
  ]
}
```

### 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 建议 | 唯一标识，也用作下拉框的 value；不写则从文件名推断 |
| `name` | 是 | 显示名称 |
| `season` | 否 | 赛季，会拼在名称后面 |
| `teams` | 是 | 队伍数组，`id` 用于在 matches 里引用，`name` 是显示名 |
| `matches` | 是 | 比赛数组 |
| `matches[].round` | 是 | 轮次，用于「截至轮次」回溯 |
| `matches[].homeGoals` / `awayGoals` | 否 | **填了就是已赛**；不填或写 `null` 就是未赛，交给模型模拟 |
| `points` | 否 | 默认 `{win:3, draw:1, loss:0}` |
| `tiebreak` | 否 | 同分排序规则，见下 |
| `slots` | 否 | 名次区间；不写则只有「冠军」一项 |

### 同分规则 `tiebreak`

按数组顺序依次比较，支持：

```
points   积分         gd      净胜球      gf      进球数
wins     胜场         losses  负场        played  已赛场次
h2hPoints  相互战绩积分   h2hGd  相互战绩净胜球   h2hGf  相互战绩进球
name     队名（保证结果确定）
```

例如中甲可以写 `["points", "gd", "gf", "wins"]`，而某些杯赛要优先看相互战绩就写
`["points", "h2hPoints", "h2hGd", "gd", "gf"]`。

### 名次区间 `slots`

`from`/`to` 是名次范围（1 起算），`type` 可自定义任意字符串，`label` 是表头显示的文字：

```json
"slots": [
  { "from": 1, "to": 1, "type": "title",   "label": "冠军" },
  { "from": 1, "to": 2, "type": "promo",   "label": "晋级" },
  { "from": 3, "to": 4, "type": "playoff", "label": "附加赛" },
  { "from": 9, "to": 10, "type": "drop",   "label": "降级" }
]
```

现成的参考例子见 [`data/demo-college-2026.json`](data/demo-college-2026.json)（6 个学院、15 场比赛）。

## 算的是什么

### 攻防强度

对每支球队用已赛比赛估计进攻与防守强度，并做**收缩**处理，避免开局样本太少而失真：

```
att_i = 场均进球 / 联赛场均          （收缩到 1.0）
def_i = 场均失球 / 联赛场均

w = 已赛 / (已赛 + 6)                // 只踢 2 场就大幅拉回平均，踢满 20 场基本用原始值
att_final = w × att + (1 − w) × 1.0
```

### 单场进球期望

```
λ_主 = 联赛场均 × 主场系数 × att_主 × def_客
λ_客 = 联赛场均 ÷ 主场系数 × att_客 × def_主
```

主场系数由数据估计（`sqrt(主场总进球 / 客场总进球)`，钳制在 1.00～1.60）。

### 采样与排名

主客队进球独立服从泊松分布。每次模拟重跑一遍剩余赛程，再按 `tiebreak` 规则排名，
统计每队最终名次的分布。跑 N 次后，`P(名次 ∈ 区间) = 命中次数 / N`。

### 内置联赛的名次区间

- **中甲** —— 冠军 / 升级（2 席）/ 降级
- **中超** —— 冠军 / 亚冠区 / 降级
- **英超** —— 冠军 / 欧冠区 / 欧联区 / 降级
- **西甲、意甲** —— 冠军 / 欧冠区 / 欧联·欧协 / 降级
- **德甲、法甲** —— 冠军 / 欧冠区 / 欧联区 / 降级 / 降级附加赛

顶级联赛不会出现"升级"这种无意义的列。

## 数据从哪来

内置联赛的数据抓自懂球帝的赛程页与积分榜页，由 GitHub Actions **每天自动刷新一次**后提交回仓库。

积分榜页很关键：中甲 2026 赛季有 4 支球队被扣分（宁波 −3、梅州 −9、苏州 −3、亚泰 −4），
赛程页看不出来。工具用「按赛果算出的积分 − 官方积分」反推扣分值，确保与官方逐队吻合。

页面上的「获取数据」读的就是这些每日刷新的快照（走 jsDelivr，自带跨域许可），
失败时自动回退到构建时内联的版本，页面始终可用。

## 已知限制

1. **不建模伤病、轮换、一周双赛** —— 只看进球率，不看赛程密度
2. **不看赛季中转会与换帅** —— 除非该队之后踢了足够多比赛
3. **附加赛只算"进入"，不算"赢下"** —— 例如升级附加赛只给"进入附加赛区"的概率
4. **同分规则需要自己配对** —— 不同联赛规则不同，用 `tiebreak` 指定
5. **精度** —— 5 万次模拟标准误约 ±0.22 个百分点；看 0.1% 量级建议 50 万次以上
6. **纯静态** —— 没有后端，数据更新依赖 GitHub Actions 的每日任务
